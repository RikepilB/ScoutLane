## Workflow

1. **`docs/PROJECT-GUIDE.md`** is the canonical user-facing guide — use cases, personas, user manual per feature
2. **`docs/API.md`** documents the authenticated HTTP surface used by the admin UI and automation flows
3. **`docs/UX-TEST-PROTOCOL.md`** is referenced before releases (Phase A smoke) and at milestone boundaries (Phase B human sessions)
4. **`docs/codebase/`** documents architecture, conventions, integrations, stack, structure, and testing for contributors
